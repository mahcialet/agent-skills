# English Review Example

## Source

> This enables the service. This improves reliability. Additionally, this
> reduces recovery time. Furthermore, this is useful for operators.

## Review

```text
[MEDIUM]
Target: all four sentences

Problem:
Each “This” may refer to the service, the enabling action, or the preceding
claim. Identical sentence patterns and transitions also give the claims equal
weight without showing evidence or causality.

Reader impact:
The reader must repeatedly resolve the referent and cannot tell which outcome
is primary.

Direction:
Name each relevant subject and group only relationships supported by the
source. Do not invent a causal mechanism or performance figure.
```
