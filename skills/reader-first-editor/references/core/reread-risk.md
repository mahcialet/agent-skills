# 読み返しリスク

読み返しリスクは、読者が未解決情報を保持したり、参照先を探索したり、関係を
復元したりする負荷として診断する。単に長い・受身・反復しているという表面
特徴だけで判定しない。

| ID | リスク | 診断の焦点 |
|---|---|---|
| RR-01 | 目的後置 | 主旨・結論・段落の役割が後半まで分からない |
| RR-02 | 主題切替え | 話題・行為者・責任主体が暗黙に切り替わる |
| RR-03 | 述語遅延 | 肯否、義務、可能性、主要動作の確定が遅い |
| RR-04 | 連体修飾負荷 | 長い修飾を保持して被修飾語を待つ |
| RR-05 | 条件積層 | 条件・例外・但し書きの範囲を保持し続ける |
| RR-06 | 指示語探索 | 「これ」「その場合」などの参照先を探す |
| RR-07 | 用語揺れ | 同一概念か別概念かを判断させる |
| RR-08 | 概念投入過多 | 一つを処理する前に新概念が続く |
| RR-09 | 階層平板化 | 主張、根拠、例、注意が同じ重さで並ぶ |
| RR-10 | 構文均質化 | 役割が違う情報を同じ構文・長さ・調子で示す |
| RR-11 | 過剰分割 | 文間の因果・条件・時間関係を読者が復元する |
| RR-12 | 行動不明 | 誰が何を判断・実行・返信するか分からない |
| RR-13 | モダリティ不明 | 必須、推奨、任意、可能性の区別が曖昧 |
| RR-14 | 係り受け多義 | 修飾・否定・並列の範囲が複数に読める |
| RR-15 | 接続標識過多 | 接続語が主要構造を覆う、または関係と合わない |
| RR-16 | 不要な再要約 | 情報が増えたか確認するために前文と照合させる |

## 重大度

- `HIGH`: 条件誤認、意味の取り違え、行動ミス、複数回の読み返しにつながる。
- `MEDIUM`: 理解速度、注意配分、情報階層の把握を明確に悪化させる。
- `LOW`: 表記、局所的な滑らかさ、軽微な反復に限られる。

同じ原因による局所的な指摘はまとめる。指摘には、対象、保持・探索・復元の
どの負荷があるか、読者への影響、意味を保つ改善方針を含める。
