# English idiomaticity

Idiomaticityは意味保存後に扱う。文法上の誤りに加えて、英語話者が語同士や情報同士の関係を
予測しにくい組合せ・配置を確認する。ただし、専門用語や組織固有表現を一般語へ勝手に
置き換えない。

## 確認点

- 不要なnominalizationがactorとactionを隠していないか。
- `make a verification of` のような不自然なlight-verb phraseを単純な動詞へ
  できるか。
- article、countability、preposition、collocationが意図に合うか。
- `in order to`、`with regard to`、`it should be noted that` などが主節を遅らせる
  だけになっていないか。
- 過度なLatinate語やbureaucratic phraseが、対象読者に必要な精度を持つか。
- source languageの語順を写したため、focusやgiven-new flowが不自然でないか。

## 禁止事項

- variationのためだけに同じ用語を類語へ変えない。
- idiomaticに見せるために新しい比喩、強調、因果、感情を加えない。
- plainな語へ変えることで法務・技術上の定義を失わない。
- registerをcasualにして対人距離を変えない。

自然な候補が複数あり、候補によって意味のshadeが変わる場合は、一つの書き換えに確定しない。
選択肢と、それぞれを選んだ場合に読者へ伝わる違いを示す。
