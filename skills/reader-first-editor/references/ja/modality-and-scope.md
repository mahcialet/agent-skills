# モダリティと適用範囲

## 強さを保存する

| 区分 | 例 | 保存する意味 |
|---|---|---|
| 義務 | 必要です、してください、しなければならない | 実施が求められる |
| 禁止 | できません、してはいけません | 実施が許されない |
| 推奨 | 推奨します、望ましい | 原則または助言 |
| 任意・許可 | できます、してもよい | 選択可能・許可 |
| 可能性 | 場合があります、可能性があります | 発生が不確実 |
| 意向・依頼 | お願いします、ご対応いただけますか | 関係性を伴う働きかけ |

丁寧にする目的で義務を推奨へ弱めたり、簡潔にする目的で不確実性を断定へ変えたり
しない。「できます」が能力・許可・可能性のどれか曖昧なら、勝手に確定しない。

## 条件・例外のスコープ

条件、否定、但し書きを、それが適用される規則や項目の近くへ置く。箇条書きへ
分けるときも、条件が全項目に掛かるか一項目だけかを保つ。例外を脚注や遠い段落
へ移して見落としやすくしない。

## 否定

「必ずしも～ない」「～以外は利用できない」「AとBを同時に使用しない」のような
否定範囲を保つ。肯定文への変換で、許可範囲・例外・強調が変わらないか確認する。

## 数量と範囲

「すべて」「一部」「原則」「通常」「少なくとも」「最大」「以内」「未満」の変更は
意味変更である。読点位置や並べ替えでも、数量詞が掛かる名詞を変えない。

## 因果と目的

「ため」が理由か目的かを文脈で確認する。原因、契機、相関、時間順序を相互に
置換しない。原文が因果を断定していなければ、新しい因果説明を追加しない。
